# 聚焦事务型本地有序索引

用户确认 Vellum 朝事务型本地有序索引库规划，而非追求与 MoonKV 的功能逐项对齐：现有交互式事务支持读取后决策、多记录修改及提交/撤销，这是选择该定位的依据。以一个可运行的文件元数据示例验证价值，范围包括本地主记录、按目录和修改时间查询的二级索引，以及同一事务中维护它们的一致性；这不意味着引入自动 schema、ORM 或完整文件系统产品。仓库 0.4.0 已实现范围/前缀游标和调用者元数据示例，公开 interface 见 [pkg.generated.mbti](../../src/pkg.generated.mbti)。

本轮保留 native、整库内存镜像、单路径单所有者、单活动事务、4096 字节页及现有键值页容量限制；不扩大并发快照、跨页值或耐久性承诺。[现有限制](../../README.md#使用前须知) 用户指出 MoonBit 多进程支持非常有限；本轮明确包含多进程可行性调查，但它不是受支持的安全功能。外部驱动在隔离的不同数据库路径启动 native 程序只能验证进程编排可行，不能证明同一路径读写安全；文件锁及同路径多进程支持仍未承诺。

新格式 v2 与禁止静默升级见 [ADR-0002](0002-v2-byte-lexicographic-order.md)；事务游标及范围/前缀 interface 见 [ADR-0003](0003-transaction-scoped-read-only-cursors.md)；只读 v1 迁移与发布/失败约束见 [ADR-0004](0004-read-only-legacy-migration.md)；调用者元数据与输入/冲突语义见 [ADR-0005](0005-caller-provided-path-metadata-example.md)。用户批准的 #2–#6 已在仓库 0.4.0 实现：真实旧库迁移逐行核对，元数据示例核对多键一致性，固定结果规模基准实际运行 1k/10k/100k 库。尚未发布到 Mooncakes，不扩大本 ADR 的并发或耐久性范围。
