# Triage labels

技能提及 canonical role 时，使用对应的 GitHub 标签。

| Canonical role | Tracker label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者尚需评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不采取行动 |
