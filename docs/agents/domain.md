# Domain docs

## 探索前

探索代码或讨论领域模型前，按 single-context 布局读取根 [GLOSSARY.md](../../GLOSSARY.md) 和 [docs/adr/](../adr/) 中与当前工作相关的 ADR。文档不存在时静默继续；术语和决策确定后由 domain-modeling 按需记录。

## 使用规则

- issue 标题、提议、假设和测试中的领域概念采用 glossary 的规范术语。
- 所需概念尚无定义时，判断是用词偏离还是模型缺口，交给 domain-modeling 澄清。
- 与既有 ADR 冲突时，指出具体 ADR 和重开讨论的理由。
